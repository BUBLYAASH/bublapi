Вопросы и ответы

Что важно знать перед знакомством с продуктом

BublAPI Dent — это готовая CRM?

Нет. BublAPI Dent — это backend-платформа и API для стоматологических клиник. Если у вас уже есть сайт или собственная система — подключим Dent API к ним. Если нет — разработаем решение под ключ: сайт клиники, CRM, личный кабинет пациента и другие необходимые сервисы.

Можно ли подключить платформу к существующему сайту?

Да. Через API сайт может получать врачей, услуги, расписание и свободные слоты, а также создавать записи пациентов.

Кому подходит BublAPI Dent?

Стоматологическим клиникам, сетям, веб-студиям, интеграторам и разработчикам, которым нужна готовая серверная основа для стоматологического сервиса.

Можно ли посмотреть продукт до внедрения?

Да. На demo.dent.bublapi.ru доступна публичная демонстрационная клиника.

Для получения доступа к возможностям сотрудников (Staff) напишите мне на email или в Telegram — я выдам отдельный демонстрационный аккаунт.
